# 產業掃描器｜今日可進場

線上網址：https://stock-scanner-ai.streamlit.app

選產業（例如「AI 產業」）→ 一次抓整個產業清單的 5 年日K → 每檔套用「小朱老師 AI 工作系統｜股票系統」同一套規則
→ 列出今天判定 **可進場** 的股票（最多 10 檔，附交易計畫），另列「等待中、最接近觸發」名單（不是買點）。

## 檔案
- `app.py`：手機畫面（選產業、掃描、排行、單檔報告）
- `scanner.py`：批次抓資料、逐檔分析、分類與排序（不含畫面，可單獨測試）
- `sectors.py`：產業股票清單（自訂分類，要增刪股票改這裡）
- `engine.py`：計算引擎，與「股票系統」App **完全相同**（不可單獨修改，兩邊要同步）
- `report_view.py`：單檔完整報告畫面（與股票系統相同）
- `chips_view.py`、`market_chips.py`：大盤三大法人籌碼（僅供對照）

## 規則
- 判斷全部來自 engine.py：10 模組、18 型態、風控否決、回測，與單檔 App 一致
- 只列真正「可進場」的股票，不足 10 檔不硬湊
- 排序：① 風險報酬比（取 1 位小數）② 回測勝率（樣本 ≥ 10 筆才採用）③ 規則符合度
- 同一產業高度連動：同時買多檔不等於分散風險

## 新增產業
在 `sectors.py` 的 `SECTORS` 加一段，例如：
```python
"散熱": {"散熱": [("3017", "奇鋐", "TW"), ("3324", "雙鴻", "TWO")]},
```
每次掃描只跑選到的產業，清單裡產業再多也不會變慢。
